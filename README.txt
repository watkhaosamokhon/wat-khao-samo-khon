เว็บไซต์วัดเขาสมอคอน — เวอร์ชันเริ่มต้น
================================================

ไฟล์หลัก
- index.html : หน้าเว็บไซต์ทั้งหมด
- styles.css : รูปแบบและการจัดวาง
- script.js : เมนูมือถือและตัวอย่างการแสดงข้อความอวยพร
- assets/ : ภาพที่นำมาใช้ในเว็บไซต์

วิธีเผยแพร่ด้วย GitHub Pages
1. แตกไฟล์ ZIP นี้
2. สร้าง repository ใหม่บน GitHub (หรือใช้ repository เดิม)
3. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ index.html อยู่ที่ระดับบนสุดของ repository
4. ไปที่ Settings > Pages
5. เลือก Deploy from a branch, เลือก branch main และ folder /(root) แล้วบันทึก
6. รอให้ GitHub แสดงลิงก์เว็บไซต์

ข้อควรรู้ก่อนเผยแพร่จริง
- แบบฟอร์มในเวอร์ชันนี้เป็นเพียงตัวอย่าง ไม่ส่งหรือจัดเก็บข้อมูล และไม่อัปโหลดสลิป
- GitHub Pages เป็นบริการเว็บไซต์แบบ static ต้องเชื่อมต่อบริการภายนอกจึงจะรับข้อมูลและไฟล์ได้
- QR Code เป็นภาพจากป้ายที่ผู้จัดทำส่งมา โปรดตรวจสอบว่าสแกนได้และชื่อผู้รับถูกต้องก่อนเผยแพร่/ใช้งานจริง
- โปรดตรวจสอบความถูกต้องของชื่อภาพ ประวัติ และข้อความทั้งหมดกับทางวัดก่อนเผยแพร่จริง
- ภาพบางภาพอาจต้องเปลี่ยนหรือปรับคำบรรยายเมื่อมีข้อมูลยืนยันเพิ่มเติม
- เว็บไซต์โหลดฟอนต์จาก Google Fonts เมื่อมีอินเทอร์เน็ต หากไม่โหลดจะใช้ฟอนต์สำรอง

การแก้ไขข้อมูล
- แก้ข้อความใน index.html
- เปลี่ยนภาพใน assets/ โดยคงชื่อไฟล์เดิมไว้ หรือแก้ชื่อไฟล์อ้างอิงใน index.html
- เพิ่มข้อมูลอื่นภายหลังได้ โดยไม่ต้องสร้างเว็บไซต์ใหม่ทั้งหมด
